# Experimentos

Os scripts desta pasta devem reproduzir a matriz experimental do TCC.

Planejamento inicial:

1. varredura do número de Reynolds;
2. independência de malha;
3. sensibilidade ao passo temporal;
4. sensibilidade à tolerância;
5. convergência do solver de pressão;
6. comparação direta FDM x FVM.

Cada execução deve registrar configuração, métricas, resíduos e campos
numéricos necessários para reprodução posterior das figuras.
